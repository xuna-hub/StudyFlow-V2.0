# StudyFlow V2.0 校园学习任务管理系统

## 一、项目简介

StudyFlow V2.0 是一款面向学生群体开发的校园学习任务管理系统，旨在帮助学生合理规划学习任务、管理任务进度、查看学习安排并进行学习数据统计。

本项目采用前端技术实现，界面简洁直观，支持任务管理、学习日历、数据统计、主题切换及本地数据持久化等功能。

## 二、项目开发背景

针对学生在日常学习过程中存在的任务分散、学习计划不清晰、任务进度难以跟踪等问题，本项目设计并开发了一套轻量化的学习任务管理应用。

通过数字化任务管理方式，帮助用户提高学习计划的可执行性和学习效率。

## 三、技术栈

| 技术 | 主要用途 |
|---|---|
| HTML | 构建网页结构 |
| CSS | 页面布局、样式及主题设计 |
| JavaScript | 实现系统交互和业务逻辑 |
| localStorage | 实现浏览器本地数据持久化 |
| JSON | 实现任务数据导入与导出 |
| Git | 项目版本管理 |

## 四、主要功能

### 1. 数据仪表盘
- 显示任务总数、待完成任务、已完成任务及逾期任务。
- 展示任务完成率。
- 展示任务分类统计和最近任务。

### 2. 任务管理
- 新增学习任务。
- 编辑已有任务。
- 删除任务。
- 标记任务完成或撤销完成。

### 3. 任务查询与筛选
- 根据关键词搜索任务。
- 按任务分类筛选。
- 按任务优先级筛选。
- 按任务状态筛选。
- 根据截止日期和优先级排序。

### 4. 学习日历
- 查看月份日历。
- 切换月份。
- 查看日期对应的学习任务。

### 5. 系统设置
- 支持浅色主题和深色主题切换。
- 支持任务数据 JSON 导出。
- 支持任务数据 JSON 导入。

### 6. 数据持久化
- 使用浏览器 localStorage 保存任务数据。
- 保存主题设置。
- 刷新页面后保留已保存的数据。

## 六、运行环境与启动方法

### 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio Code
- 浏览器：Chrome、Edge 等现代浏览器
- 辅助工具：VS Code Live Server 插件

### 启动步骤

1. 使用 Visual Studio Code 打开项目文件夹。
2. 进入 `01_项目源代码` 文件夹。
3. 找到 `index.html`。
4. 右键选择 Open with Live Server。
5. 浏览器自动打开系统页面，即可开始使用。

本项目为纯前端应用，无需部署后端服务器。

## 七、数据存储说明

系统采用浏览器 localStorage 进行本地数据存储。

主要存储键：

- `studyflow_tasks_v1`：保存任务数据。
- `studyflow_theme_v2`：保存主题设置。

系统支持 JSON 数据导入与导出，便于备份和迁移任务数据。

注意：localStorage 数据保存在当前浏览器环境中，清除浏览器数据或更换浏览器可能导致原有数据无法直接访问，建议定期导出备份。
