# StudyFlow V2.0 页面原型与功能对应说明

## 一、页面原型设计说明

StudyFlow V2.0 采用模块化页面布局，将学习任务管理、学习数据统计、学习日历和系统设置整合在统一界面中。

本说明根据最终实现的页面结构和功能进行回溯整理，用于展示系统页面组成、功能布局及页面之间的关系，不作为开发前原始原型文件。

## 二、整体页面布局

系统采用左侧导航栏与右侧主内容区域相结合的布局方式。

### 1. 左侧导航区域

主要负责系统功能页面切换，包含：

- 数据仪表盘
- 全部任务
- 学习日历
- 系统设置

### 2. 右侧内容区域

根据用户选择的功能模块展示对应页面内容，实现不同业务功能之间的切换。

## 三、主要页面原型说明

### 3.1 数据仪表盘页面

**页面定位：** 系统首页，用于展示学习任务整体情况。

**页面主要元素：**
- 任务总数统计卡片
- 待完成任务统计
- 已完成任务统计
- 逾期任务统计
- 任务完成率图表
- 任务分类统计
- 最近任务列表

**功能说明：**

用户进入系统后，可以快速了解当前任务数量、完成进度和逾期情况，为学习计划调整提供参考。

**对应运行截图：** 01_系统仪表盘.png

### 3.2 全部任务页面

**页面定位：** 学习任务的集中管理区域。

**页面主要元素：**
- 任务列表
- 新增任务入口
- 任务编辑功能
- 任务删除功能
- 完成状态操作
- 关键词搜索
- 分类和优先级筛选
- 排序功能

**功能说明：**

用户可以在该页面创建和管理学习任务，并通过搜索、筛选和排序快速定位目标任务。

**对应运行截图：**
- 02_全部任务.png
- 03_任务搜索筛选.png

### 3.3 学习日历页面

**页面定位：** 学习任务的时间安排和日期查看区域。

**页面主要元素：**
- 月份显示
- 上一月和下一月切换
- 今天定位功能
- 日期任务标记
- 日期任务列表

**功能说明：**

通过日历视图展示任务与日期之间的关系，帮助用户了解不同日期的学习安排。

**对应运行截图：** 04_学习日历.png

### 3.4 系统设置页面

**页面定位：** 系统个性化设置和任务数据管理区域。

**页面主要元素：**
- 浅色主题设置
- 深色主题设置
- JSON数据导出
- JSON数据导入

**功能说明：**

用户可以调整系统显示主题，并对学习任务数据进行备份和恢复。

**对应运行截图：**
- 05_系统设置.png

## 四、页面之间的功能关系

系统页面之间通过左侧导航栏进行切换，各页面围绕学习任务数据展开。

主要业务关系如下：

1. 用户在任务页面创建或修改任务。
2. 系统保存任务数据。
3. 仪表盘根据任务数据更新统计结果。
4. 学习日历根据任务截止日期展示对应任务。
5. 用户可以通过系统设置导出或导入任务数据。

## 五、原型与实际实现的对应关系

| 页面原型模块 | 最终实现功能 | 对应源代码 |
|---|---|---|
| 数据仪表盘 | 任务统计、完成率、分类统计 | index.html、style.css、script.js |
| 全部任务 | 任务新增、编辑、删除和完成 | index.html、script.js |
| 搜索筛选 | 关键词搜索、分类和优先级筛选 | index.html、script.js |
| 学习日历 | 月份切换、日期任务显示 | index.html、script.js |
| 系统设置 | 主题切换、JSON导入导出 | index.html、script.js |
| 数据持久化 | 任务和主题本地保存 | script.js |

## 六、原型设计总结

通过对系统页面结构和功能模块进行梳理，形成了以数据仪表盘为入口、以学习任务管理为核心、以学习日历和系统设置为辅助的页面组织方式。

页面布局与实际功能相互对应，能够满足学生日常学习任务管理的基本需求。

本说明结合最终系统运行截图和源代码整理，用于展示页面设计思路及最终实现之间的关系。
