# StudyFlow V2.0 AI提示词迭代记录

## 一、AI辅助开发说明

本项目采用AI辅助开发与人工操作相结合的开发方式。在项目开发过程中，利用AI辅助进行需求分析、功能规划、代码生成与优化、问题排查及测试方案设计。

开发者根据项目实际需求，将完整系统拆分为多个功能模块，分阶段向AI提出开发要求，并根据实际运行效果进行检查和调整。

本记录根据项目开发过程及已有对话进行回溯整理，不作为开发当时逐条保存的原始提示词日志。

## 二、AI辅助开发工具

| 工具 | 主要用途 |
|---|---|
| ChatGPT | 需求分析、提示词设计、代码辅助、问题排查及测试指导 |
| Visual Studio Code | 项目代码编写和管理 |
| Live Server | 本地网页运行与功能验证 |

## 三、提示词分阶段设计

### 第一阶段：项目需求分析

**开发目标：**

明确校园学习任务管理系统的用户需求、功能范围和整体开发方向。

**整理后的代表性提示词：**

请帮助我设计一个面向学生群体的校园学习任务管理系统，分析学生在学习任务管理中遇到的问题，规划系统核心功能，包括任务管理、学习计划、任务统计和日历展示，并给出清晰的功能模块划分。

**AI辅助内容：**

- 分析目标用户需求。
- 规划系统核心功能。
- 梳理系统页面结构。
- 明确项目开发方向。

**人工处理：**

结合项目实际开发能力和课程要求，确定最终功能范围。

### 第二阶段：系统页面与功能规划

**开发目标：**

规划系统页面布局和主要交互模块。

**整理后的代表性提示词：**

请根据校园学习任务管理系统的需求，规划一个现代化、简洁的学习管理界面，包含左侧导航栏、数据仪表盘、全部任务、学习日历和系统设置，要求布局清晰、操作方便，并考虑页面适配。

**AI辅助内容：**

- 页面布局规划。
- 导航栏结构设计。
- 功能页面划分。
- 视觉样式建议。

**人工处理：**

根据实际页面效果调整界面布局，并保留左侧固定导航栏设计。

### 第三阶段：任务管理功能开发

**开发目标：**

实现学习任务的基本管理功能。

**整理后的代表性提示词：**

请使用JavaScript设计学习任务管理功能，实现任务新增、编辑、删除、完成状态切换，并支持任务分类、优先级和截止日期设置。要求各项操作完成后，页面能够及时更新。

**AI辅助内容：**

- 任务数据结构设计。
- 任务增删改查逻辑。
- 完成状态管理。
- 页面交互处理。

**人工处理：**

在VS Code中运行系统，通过实际操作检查任务是否能够正确创建、修改、删除和完成。

### 第四阶段：搜索筛选与统计功能开发

**开发目标：**

提高任务查找效率，并实现学习数据统计。

**整理后的代表性提示词：**

请为学习任务管理系统增加关键词搜索、分类筛选、优先级筛选、任务状态筛选和排序功能，同时实现任务总数、待完成数量、已完成数量、逾期数量及完成率统计。

**AI辅助内容：**

- 搜索和筛选逻辑。
- 任务排序。
- 任务状态统计。
- 仪表盘数据更新。

**人工处理：**

通过添加不同类别和状态的任务，检查筛选结果和统计数据是否符合实际情况。

### 第五阶段：学习日历与数据持久化

**开发目标：**

实现学习日历和本地数据保存。

**整理后的代表性提示词：**

请使用JavaScript实现学习日历，支持月份切换和日期任务显示。同时使用浏览器localStorage保存任务数据，保证页面刷新后能够读取之前保存的任务。

**AI辅助内容：**

- 日历月份切换。
- 日期任务显示。
- localStorage数据保存。
- 页面刷新后的数据读取。

**人工处理：**

实际刷新浏览器，检查任务数据是否保留，并测试日历月份切换和任务显示。

### 第六阶段：JSON数据管理与系统优化

**开发目标：**

增加数据导入导出功能，并完善系统设置。

**整理后的代表性提示词：**

请为系统增加JSON任务数据导入和导出功能，导入时检查数据格式，处理不符合要求的JSON文件，并在导入失败时提供明确提示。同时增加浅色和深色主题切换。

**AI辅助内容：**

- JSON数据导出。
- JSON数据导入。
- 数据格式检查。
- 主题切换功能。
- 异常提示优化。

**人工处理：**

通过合法JSON备份文件和格式错误的JSON文件进行实际测试，检查导入结果和错误提示。

### 第七阶段：代码检查与功能测试

**开发目标：**

检查项目代码，发现问题并验证系统功能。

**整理后的代表性提示词：**

请检查项目的HTML、CSS和JavaScript代码，分析系统页面结构、业务逻辑和本地存储实现，检查是否存在功能逻辑问题，并帮助设计任务管理、搜索筛选、日历、数据导入导出和持久化测试方案。

**AI辅助内容：**

- 源代码结构检查。
- 业务逻辑分析。
- 功能测试方案。
- 异常数据测试建议。
- 项目文档整理。

**人工处理：**

使用浏览器实际运行系统，逐项操作并记录测试结果。

## 四、提示词迭代与优化总结

项目开发过程中，采用分阶段、分模块的提示词设计方式，而不是一次性要求AI完成整个系统。

提示词优化主要体现在以下方面：

1. 从整体需求逐步细化到具体功能。
2. 明确开发技术和功能范围。
3. 将复杂功能拆分为可独立验证的小任务。
4. 根据系统实际运行情况调整提示词要求。
5. 将AI建议与实际代码效果进行对照。

这种方式有助于降低复杂任务的开发难度，提高AI辅助开发的效率。

## 五、AI辅助与人工工作的分工

| 工作内容 | AI辅助部分 | 人工完成部分 |
|---|---|---|
| 需求分析 | 提供需求分析和功能规划建议 | 确定最终项目方向 |
| 页面设计 | 提供布局和视觉设计建议 | 在VS Code中调整和确认页面 |
| 功能开发 | 提供代码思路和实现建议 | 运行代码并检查实际效果 |
| 问题排查 | 分析代码和提供排查方案 | 根据运行结果验证问题 |
| 功能测试 | 提供测试方案和测试用例 | 实际操作并记录结果 |
| 项目文档 | 辅助整理报告和说明 | 核对项目实际情况并确认内容 |

## 六、AI辅助开发成果

通过AI辅助与人工验证相结合，最终完成了StudyFlow V2.0的主要功能，包括：

- 数据仪表盘。
- 学习任务增删改查。
- 搜索、筛选与排序。
- 学习日历。
- 浅色和深色主题切换。
- JSON数据导入与导出。
- localStorage本地数据持久化。
- 异常JSON格式识别与提示。

## 七、总结

本项目通过AI辅助开发，将复杂的系统开发过程拆分为需求分析、页面规划、功能实现、代码检查和测试验证等阶段。

在开发过程中，AI主要发挥辅助分析、代码建议和问题排查作用，开发者负责需求确定、代码运行、实际测试和最终结果确认。

通过本次项目实践，进一步认识到AI并不能完全替代开发者。只有结合明确的需求、合理的提示词、人工检查和实际测试，才能更有效地利用AI完成软件开发任务。
